Deterministic cellular material engine

State Space

Movement, heat, phase change, combustion and structural failure share one replayable state. Water freezes into bonded ice, fuel releases its stored energy, and a burning support can break and drop what it was holding.

Open the engine lab Source on GitHub

This browser does not expose WebGPU, so only the engine lab will run here. Try a recent desktop version of Chrome or Edge for the other demos.

Before you start

  • Every demo is a static page. The simulation runs in your browser.
  • The engine lab runs on the CPU. Every other demo needs WebGPU.
  • Demos tagged paused wait for you to play or step.
  • The 3D worlds use experimental APIs, and the larger ones need a capable graphics card.
