# C1: authoritative contracts

## Scope

Establish the shared catalog and encoding boundary without declaring the CPU
physics conformant. C2 owns actual rule parity; C3 owns energy/fidelity changes.
The existing game work is preserved and used as integration regression evidence.

## Implementation

- `engine/materials.json` is the validated source for material properties, IDs,
  encoding fields, phase/flag values, default placement state, and cold offsets.
- `engine.generate` produces Python, TypeScript, browser JavaScript, WGSL bitmask
  definitions, browser shader copies, and the shader bundle. It has a check mode.
- `ENGINE_CONTRACT.md` documents row-major state, closed boundaries, absolute tick
  semantics, format versions, catalog identity, explicit external interventions,
  backend status, and current physical approximations.
- Python/TypeScript validators reject malformed dimensions, cells, tick counts,
  and incompatible snapshot metadata before coercion or GPU dispatch. Python
  snapshots copy their data and expose read-only cells.
- GPU continuation accepts an absolute start tick; zero-tick runs return identity
  and finite timing. Engine paths are checkout-relative.
- Both game clients consume shared definitions at their engine boundary. The
  fighter remains a documented lossy material import.

## Verification

Run `python -m engine.verify --report docs/checkpoints/c1-verification.json` from
the repository root after `uv sync --dev` and `npm ci` in the root and both game
directories. The report records every command and its output, source hashes, and
whether source changed during verification. It must say `passed: true` before
C1 is marked complete.

The gates include engine-specific lint, Ruff, Python contract/GPU tests, the
original cascade and invariant suites, TypeScript engine tests and type checking,
and both game tests/builds. The new suite includes 100,003 packed Python values,
10,000 seeded browser values, all cold-table slots, and malformed-input mutations.

## Remaining scope

This checkpoint does not prove CPU/GPU physics equivalence, accurate energy
accounting over long horizons, portable installed GPU assets, trusted evolution,
or structural dynamics. Those requirements remain open in C2-C7. The game builds
still report their existing large-bundle warning; this is not an engine-fidelity
failure. No source has been committed or published by this checkpoint.

Final C1 run: 2026-09-07, 11/11 commands passed with unchanged source hashes.
Python: 23 tests; browser engine: 7; fighter: 104; Relic Line: 37.
The original 200-tick cascade and all 67 invariant/fuzz cases also passed.
