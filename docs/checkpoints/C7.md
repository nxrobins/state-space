# C7: engine reference release

Status: verified. The final 16-gate aggregate completed on
2026-09-08 at 01:52:20 UTC with unchanged sources. The completion audit verifies
all seven checkpoints and leaves no outstanding C1–C7 requirements.

The deliverable is the local/private 0.3 reference engine and its live public-SDK
laboratory. No package, site or source commit is published by this checkpoint.
The games remain integration clients. The capability and extension guide is
[`../CAPABILITIES.md`](../CAPABILITIES.md).

## Implementation and direct evidence

`examples/lab/` runs five live experiments through the public SDK: a supported
span, coherent falling plate, burning support, melting/freezing and a custom
copper registry. The controller serializes operations and replaces a field only
after a candidate backend/session has been created and restored successfully.
The renderer consumes a committed copy of public samples and diagnostics.

Users can run/step/reset, choose CPU or WebGPU without resetting the simulation,
inspect cells and pass reports, view bonds/temperature/integrity/support, edit
materials/energy/bonds/anchors, and save or exchange a complete session with its
catalog. Keyboard inspection and intervention use the same cell coordinates.
Import and backend transfer begin a new accounting baseline, as documented by
the public snapshot contract.

`engine.verify` now requires 16 gates, adding live-lab properties and a real
hardware-browser gate. The latter starts a private named browser session and an
ephemeral localhost server, regenerates the native corpus, compares every pass
against CPU/WebGPU, verifies five live scenarios and UI operations, and compares
the actual browser SDK result to an independently installed native client.
Both resources close after verification; missing capability or evidence fails.

The first completed browser probe is `c7-browser-third/report.json`: 31 native
scenes, 2,304 complete pass comparisons, five live scenes, exact cross-backend
continuation, installed SDK parity, and no page errors. The initial two attempts
are retained as unsuccessful automation evidence, not engine verification.
Final release acceptance uses the aggregate report and its fresh browser artifacts.

## Limits and subsequent work

The model remains a deterministic cellular approximation. It has no continuum
pressure, fluid velocity, calibrated SI units, elasticity, structural rotation,
angular momentum or mechanical-energy ledger. Device claims are bounded by the
recorded adapters and workloads. Exact conservation and cross-backend agreement
do not establish real-world physical accuracy.

Large-world latency is still constrained by host structural planning and full
readbacks. The reference release makes that cost and its behavior measurable;
it does not claim 512² worlds at 60 Hz. The next proposed checkpoint is a measured
reduction of complete-tick cost with unchanged positive behavior and complete
state. Pressure/velocity or rotation/elastic response would be separate physical
contract extensions. They are future directions, not missing C1–C7 deliverables.
