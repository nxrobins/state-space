## Production integration

- Schema 3 requires packed cells, conserved energy and persistent structure in
  every snapshot. All 24 cold-table properties are defined, including cohesion
  and softening. The local SDK packages are version 0.3.0.
- Native GPU, CPU and WebGPU run structural planning/application before movement,
  then heat/phase/reactions and final bond normalization: 18 passes, 36 variants.
  All three coordinates survive transport and restart. Broken pins remain fixed;
  both swap endpoints are protected from independent movement.
- Public placement, anchoring, break/repair/weld, inspection and sampling carry
  structural state. Melting removes pins; solidification creates fresh bonds.
  Cooling and repair alone never silently weld a fracture.
- The standalone sandbox now uses the supported SDK. Browser interaction placed
  29 metal cells, translated their whole fragment by two rows, preserved energy,
  and verified exact snapshot replay and restoration. The 31-scene browser corpus
  agrees with native/CPU after all 2,304 passes, including complete diagnostics,
  inspection-disabled stepping and serialized continuation.
- Installed wheel/npm clients match all three coordinates and 54 pass deltas.
  The SDK browser result also matches the installed native client. Game integration
  retains the explicitly lossy fighter material import across schemas 1/2/3;
  Relic Line continues to use the shared public field API.
- Evolution now targets structural application and normalization as well as the
  existing kernels. Reference passes, final hashes, repeated runs and restarts
  include structure. Invalid completed GPU output retains immutable raw arrays
  and its failed tick, without committing it to the public field.

## Implemented prototype

- Persistent reciprocal cardinal bonds, per-cell integrity, explicit pins, and
  fresh solidification requests in a separate u32 coordinate. Contact supports
  another fragment without automatically welding it.
- Global support distances, deterministic exact integer load splitting, balanced
  reactions, capacity reduced by damage/temperature, progressive overload damage,
  and fragments recomputed after failure.
- Coherent one-cell downward translation, including stacked/interlocking contact
  dependencies. Transport is a permutation of complete packed/energy/structural
  state; displaced fluid cells each retain exactly one destination.
- Independent scalar Python and TypeScript planners, plus a faster array-based
  Python implementation. Components use DFS, union/find, and monotone root
  hooking/pointer compression respectively. All solve global connectivity to
  completion, including support paths longer than 900 cells.
- An actual native GPU transport probe using the planned eight-storage-binding
  ABI. It rejects stale input arrays and geometry before compiling or allocating.
  It is not yet a production compositor pass or a browser WebGPU implementation.

This remains a quasistatic cellular strength approximation, without rotation,
elastic strain, angular momentum, SI-calibrated stress, or mechanical energy.
Structural damage changes no thermal/latent/chemical energy. Only cohesive cells
participate in the current structural load calculation; granular/fluid mass is
not modeled as an applied structural pressure field.
