# Third-party material assets

The optional naturalistic 3D renderer uses **Rock Boulder Dry**, photographed by
Dimitrios Savva and processed by Rico Cilliers, from
[Poly Haven](https://polyhaven.com/a/rock_boulder_dry).

The diffuse, OpenGL normal and roughness maps are distributed under
[CC0 1.0](https://polyhaven.com/license). The original 1024×1024 JPEGs are embedded
unchanged in the optional renderer module. No runtime external asset request is
made. The material's tint and lighting are applied by State Space's own shaders.

Source URLs, byte counts and SHA-256 digests are recorded in
[`engine/experimental/ROCK_TEXTURES.md`](../engine/experimental/ROCK_TEXTURES.md).
