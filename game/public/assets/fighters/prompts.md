# Fighter Portrait Prompts

These generated portraits are original fictional characters for the Element Fighter prototype. They are used as character-select, VS, HUD, and result-screen assets.

## Water: Tide Warden

Use case: stylized-concept
Asset type: browser fighting game character portrait for Water fighter, later used in character select, VS screen, HUD crop, and results screen.
Primary request: Create a production-grade stylized realistic game character portrait of an elemental water martial artist.
Scene/backdrop: cinematic underground arena atmosphere with abstract water ribbons and mist, no readable signage.
Subject: athletic adult water fighter, calm focused expression, disciplined stance, blue-gray combat robes with wet fabric texture, subtle armor wraps, water ribbons orbiting both hands.
Style/medium: high-detail stylized realistic game key art, not photoreal celebrity, not anime, clean readable silhouette.
Composition/framing: waist-up portrait, centered, looking slightly toward camera, generous head and shoulder padding for UI crops.
Lighting/mood: cool rim light, soft arena key light, reflective water highlights, focused and controlled.
Color palette: deep navy, teal, pale cyan, muted steel gray.
Materials/textures: water, wet cloth, leather wraps, subtle spray droplets.
Text: none.
Constraints: original fictional character, no text, no logo, no watermark, no real person likeness, no extra characters, no weapons, no hands cropped out.
